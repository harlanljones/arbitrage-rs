# Results dashboard

- **Scope and mode:** Persuade first, inspect second. The public React dashboard at `dashboard/src/App.tsx` shows project success without turning paper-trading evidence into a live-trading claim.
- **Audience and job:** Public evaluators should understand the result in one viewport; engineers can inspect percentiles, host provenance, methodology, tables, and dated JSON snapshots.
- **Direction:** Proof Stack expressed as an audited proof ledger. Approved comp: `.impeccable/mocks/proof-stack-ledger.png`. The memorable moment is a large p99 measurement paired with a true logarithmic budget ruler, followed by one continuous evidence rail.
- **Constraints:** Synthetic workload and paper trading stay visible at every breakpoint. Cross-host results are comparisons, not trends. Core interface text and graphics remain semantic HTML/SVG.
